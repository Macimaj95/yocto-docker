# Yocto Docker

Simple docker dev. env. for Yocto Projects
Yocto build data id intentionally kept outside container.

## Targets:
- BeagleBone Black - in progress
- ST MP1 - in future
- Raspberry Pi - in future 

## Structure
- `Dockerfile` - Docker image definition
- `docker-compose.yml` - container configuration
- `scripts/` - helper scripts
